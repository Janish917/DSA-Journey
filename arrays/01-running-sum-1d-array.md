# Running Sum of 1d Array

**Source:** LeetCode 1480
**Pattern:** Prefix Sum
**Difficulty:** Easy

## Approach
Maintain a running total while iterating through the array, storing the 
cumulative sum at each index into the result array.

## Complexity
- Time: O(n)
- Space: O(n) (for the output array)

## What I learned
This is the base pattern for prefix sums — used later in subarray sum 
problems.
